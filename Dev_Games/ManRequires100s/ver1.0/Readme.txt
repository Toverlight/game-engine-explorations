ManRequires100s
Developed by Toverlight
Current version: 1.0  1/11/2024 (Initial)

Rules:
游戏开始之前，你可以选择难度。
敌人的数目取决于输入的难度数字。
游戏开始，玩家（以‘@’显示）出生在矩形地图四角之一（各有特定范围）的某个位置，每个敌人（以‘#’显示）则出生在中央一片范围内的随机位置，并以不同的速度与追向你，针对敌群拥挤情况，它们还会采取不同的行动策略。
你的唯一目标，就是逃避敌人追捕，并坚持100秒，100秒后，就是你的胜利！
而中途被任意一个敌人追上，都会导致游戏结束！
没事，下一个100秒，必定是你的胜利！
Operations:
玩家可以上下左右移动，对应按键是wsad。
点按：向对应方向前进一格（慎走）
长按：向对应方向前进一格后，持续高速前进（蓄力后奔跑）
Points for attention:
游戏以控制台形式呈现：
1.为防止输出乱码，可提前将系统编码设置为utf-8或unicode；
2.为防止游戏界面显示错乱和不断滚动刷屏，请在打开exe后按Ctrl+后滚鼠标滚轮适当缩小控制台字体。
